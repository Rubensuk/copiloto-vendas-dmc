## O que é?

Um protótipo **interativo** que ajuda representantes de negócios (RNs) da DMC a gerar roteiros de abordagem de vendas persuasivos para os produtos Ambev/Heineken. Ele simula um assistente de IA, substituindo variáveis como *vendedor*, *cliente*, *produto* e *objeção*.

## Como usar

1. **Abra a URL** acima em qualquer navegador.
2. Preencha os campos (nome do vendedor, cliente, escolha o produto e a objeção).
3. Clique em **Gerar Roteiro Inteligente**.
4. O roteiro será exibido em 4 passos com técnicas avançadas de negociação.
5. Use o botão **Copiar** para levar o texto ao seu celular ou bloco de notas.

## Funcionalidades principais

- **Portfólio completo** da Ambev (cervejas premium, mainstream, refrigerantes, zero, drinks prontos, etc.).
- **Campo livre** para registrar objeções personalizadas.
- **Prompt Blueprint** mostrando exatamente o que seria enviado a um modelo de IA.
- **Design premium** com dark‑mode, glassmorphism e micro‑animações.
- **QR Code** para acesso rápido.
